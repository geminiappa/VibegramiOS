# Vibegram iOS — нативный интерфейс SwiftUI

Этот проект заменяет прежнюю WebView-оболочку на нативные экраны SwiftUI и использует текущий backend `https://vibegramm.onrender.com`.

## Что реализовано

- Нативный onboarding и выбор `@username` / имя.
- Вкладки «Чаты», «Контакты», «Каналы», «Профиль».
- Обновление данных с сервера примерно каждые 3,5 секунды и обновление жестом pull-to-refresh.
- Отправка текстовых сообщений, отметка прочтения, история сообщений и базовые состояния сообщений.
- Поиск контактов и каналов, просмотр профилей и карточек каналов.
- Создание каналов, подписка, просмотр постов и публикация для владельца канала.
- Редактирование профиля, выбор изображения через PhotosPicker и отправка аватарки на backend.
- Premium/verification/team badges рендерятся на основе полей, приходящих от сервера.
- Интерфейс в тёмном iOS-стиле с адаптацией к размеру экрана.

## Открытие в Xcode

1. Открой `Vibegram.xcodeproj` в Xcode 15+.
2. Выбери схему `Vibegram` и iPhone Simulator.
3. Нажми Run. Для реального устройства задай свою Team в `Signing & Capabilities`.
4. Для CI используй `.github/workflows/build-ipa.yml` и проверь результат в GitHub Actions.

## Ограничения существующего сервера

Текущий backend Vibegram принимает имя пользователя в API вместо защищённой пользовательской сессии и не предоставляет полноценного механизма регистрации / паролей / OAuth. Этот iOS-клиент повторяет совместимый с имеющимся сервером способ идентификации по username. **Не используйте это как безопасную публичную production-авторизацию** до добавления серверной аутентификации и проверок прав.

Push-уведомления APNs при полностью закрытом приложении не включены. Для этого нужны Apple Push Notification service, device-token registration, APNs credentials и серверная отправка push.

Также текущие API не предоставляют полноценной доставки файлов/голосовых сообщений и WebRTC-звонков для нативного клиента. Интерфейс и backend можно расширять следующими этапами.

## Сборка IPA и sideloading

См. `УСТАНОВКА-IPA.md`. Workflow проверяет структуру `Payload/Vibegram.app`, наличие `CFBundleExecutable` и `CFBundleIdentifier`, и архитектуру `arm64`. Полученный IPA **не подписан**; для установки импортируй сам `.ipa` в AltStore Classic, SideStore или Sideloadly.
